# 大富豪オンライン

友達とリアルタイムでオンライン対戦できる大富豪(大貧民)アプリです。
Node.js + Socket.io で動くWebアプリで、ブラウザだけで遊べます。

## 収録ルール

- 2〜6人まで対応
- 8切り(8を出すと場が流れて続けて出せる)
- 革命(4枚以上の同じランクを出すと強さが逆転)
- しばり(同じスートの出し方が2回続くと、場が流れるまでそのスート縛りになる)
- ジョーカー、スペードの3返し(ジョーカー単騎をスペ3で返せる)
- あがり順位(大富豪・富豪・平民・貧民・大貧民)
- 次のラウンドでのカード交換(大富豪⇔大貧民は2枚、富豪⇔貧民は1枚)

初回ラウンドはクラブの3を持っている人からスタートします。2ラウンド目以降は前回の大貧民からスタートします。

## 必要なもの

- [Node.js](https://nodejs.org/) 18以上(推奨: 18〜22)

## セットアップと起動方法

1. このフォルダをダウンロード・展開します。
2. ターミナル(コマンドプロンプト)でこのフォルダに移動します。

   ```bash
   cd daifugo-online
   ```

3. 依存パッケージをインストールします(初回のみ)。

   ```bash
   npm install
   ```

4. サーバーを起動します。

   ```bash
   npm start
   ```

5. ターミナルに `http://localhost:3000` と表示されたら起動成功です。ブラウザで開いてください。

## 友達を招待する方法

サーバーを起動したパソコン(ホスト)が「大富豪サーバー」になります。友達がアクセスできるようにするには、いくつか方法があります。

### 方法A: 同じWi-Fiにいる場合(一番簡単)

1. ホストのパソコンのローカルIPアドレスを調べます。
   - Windows: コマンドプロンプトで `ipconfig` → 「IPv4 アドレス」(例: `192.168.1.5`)
   - Mac: システム設定 → Wi-Fi → 詳細 で確認、またはターミナルで `ipconfig getifaddr en0`
2. 友達に `http://<そのIPアドレス>:3000`(例: `http://192.168.1.5:3000`)にアクセスしてもらいます。
3. ホストのファイアウォールでポート3000への接続を許可する必要がある場合があります。

### 方法B: 別々の場所からインターネット経由で遊ぶ場合

同じWi-Fiにいない友達と遊ぶには、外部からアクセスできるようにする必要があります。おすすめは以下のいずれかです。

- **ngrok** などのトンネリングサービスを使う(`ngrok http 3000` を実行すると発行されるURLを友達に共有)
- クラウドサーバー(Render, Railway, Fly.io など)にこのフォルダをデプロイする(Node.jsアプリとしてそのままホスティング可能です)
- ルーターのポート開放(ポートフォワーディング)を設定する

いずれの方法も、ホストのプライバシー・セキュリティに関わるため、信頼できる友達内で使う想定にしてください。

## 遊び方

1. 1人が「新しいルームを作る」でルームを作成し、発行された4桁のルームコードを友達に共有します。
2. 友達は「ルームに参加する」でニックネームとルームコードを入力して参加します。
3. 2人以上集まったら、ホストが「ゲーム開始」を押します。
4. 自分の番になったら手札をタップして選択し、「出す」または「パス」を押します。
5. カードを出せなくなったらパスします。全員がパスすると場が流れます。
6. 手札がなくなった人から順にあがっていきます。
7. 全員があがるとラウンド終了。結果が表示されます。次のラウンドはホストが「次のラウンドへ」を押すと、前回の順位に応じたカード交換が行われてから再スタートします。

## ページを閉じてしまったら

同じブラウザ・同じ端末であれば、ページを開き直すと自動的に元のルーム・ゲームに再接続されます(ログイン情報はブラウザに保存されています)。別の端末からは同じプレイヤーとしては参加できないのでご注意ください。

## フォルダ構成

```
daifugo-online/
├── package.json
├── README.md
├── server/
│   ├── index.js   … Express + Socket.io サーバー本体
│   ├── rooms.js   … ルーム(ロビー)管理
│   └── game.js    … 大富豪のゲームロジック
└── public/
    ├── index.html … 画面のHTML
    ├── style.css  … デザイン
    └── client.js  … クライアント側のロジック
```

## カスタマイズのヒント

- ルールを変えたい場合は `server/game.js` を編集してください(例: 11バック、階段、5枚出しなどを追加できます)。
- 見た目を変えたい場合は `public/style.css` を編集してください。
- ポート番号を変えたい場合は `PORT` 環境変数を指定して起動できます。

  ```bash
  PORT=8080 npm start
  ```
